# Lokale Lokaler

Lokale Lokaler er en lille React Native-applikation, som giver brugeren
et overblik over forsamlingshuse og selskabslokaler.

Applikationen kan bruges til at finde lokaler til eksempelvis:

- Fødselsdage
- Bryllupper
- Konfirmationer
- Familiefester
- Andre arrangementer

## Funktioner

Applikationen indeholder:

- En forside
- En liste over alle lokaler
- En detaljeside for hvert lokale
- Navigation mellem de forskellige screens
- Information om pris, adresse og kapacitet
- Separat styling-fil
- Genbrugelig Button-komponent

## Screens

### HomeScreen
Forsiden introducerer brugeren til applikationen.

Herfra kan brugeren trykke på "Se alle lokaler".

### ListScreen
Viser en liste over alle tilgængelige lokaler.

Brugeren kan trykke på et lokale for at se flere oplysninger.

### DetailScreen
Viser detaljer om det valgte lokale:

- Adresse
- Pris
- Kapacitet
- Hvad lokalet primært er egnet til

## Teknologier

- React Native
- Expo
- JavaScript
- React Navigation
